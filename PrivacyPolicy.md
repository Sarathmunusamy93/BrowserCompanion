Privacy Policy

Last updated: February 2026

Track Me (“the extension”) is committed to protecting your privacy. This Privacy Policy explains how the extension handles user data.

1. Information We Collect

The extension does not collect, transmit, or store personal user data on external servers.

The extension may access the following data locally within the user’s browser only:

Open browser tabs

Browsing history

Frequently visited websites (top sites)

This data is used solely to provide browsing activity insights to the user.

2. How Information Is Used

The accessed data is used only for:

Tracking browsing activity

Generating summaries and insights for personal awareness and productivity

All processing occurs locally in the browser.

3. Data Storage

Any data used by the extension is stored locally using Chrome’s storage APIs and remains under the user’s control.
No data is uploaded, shared, or synchronized with external services.

4. Data Sharing

The extension:

❌ Does not sell user data

❌ Does not share data with third parties

❌ Does not use data for advertising or analytics

5. Remote Code & Third-Party Services

The extension does not load or execute remote code.
No third-party services or external scripts are used.

6. User Control

Users can remove all stored data at any time by:

Clearing extension data from Chrome settings

Uninstalling the extension

7. Changes to This Policy

If this Privacy Policy is updated in the future, changes will be reflected on this page.
